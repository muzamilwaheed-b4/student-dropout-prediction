Project Summary

This system was implemented as part of the Machine Learning course curriculum. It evaluates four classical classifiers trained on the UCI Higher Education Retention dataset.

  • Algorithms Evaluated: K-Nearest Neighbors, Decision Tree, Random Forest, Logistic Regression.
  • Data Preprocessing: Missing value verification, IQR outlier capping for entrance grades, and standard normalization.
  • Imbalance Treatment: Synthetic Minority Over-sampling Technique (SMOTE) applied on training splits.
  • Clustering Analysis: K-Means clustering (k=3) for risk group identification.
